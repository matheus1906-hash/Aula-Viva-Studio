# Histórico de versões

## 3.0.0
- **AulaViva Studio passa a ser um app web**, publicado no GitHub Pages. A versão desktop (Python + Qt) foi preservada no branch `desktop-legacy`.
- Interface em português, inglês e espanhol; materiais gerados no idioma escolhido.
- Exportação em PDF interativo, Word, PowerPoint, HTML, Markdown, TXT e JSON.
- 70 modelos prontos, 13 geradores de atividades comuns, estúdio de vídeos animados, estúdio de fontes, chat livre, biblioteca de conteúdos.
- Livros e e-books: 118 livros reais em domínio público com capa, acervo comentado, busca inteligente e ABNT.
- IA incluída no claude.ai ou com a chave do professor (Gemini, Groq, Cerebras, OpenRouter, Mistral, Hugging Face, Ollama, Claude, OpenAI, DeepSeek).
- Visual novo, acessível (WCAG AA) e otimizado para celular.

As versões 1.x e 2.x (desktop) estão descritas no branch `desktop-legacy`.
